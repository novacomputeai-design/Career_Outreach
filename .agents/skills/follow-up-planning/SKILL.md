# follow-up-planning

Use only authorized private history, not inference. Confirm last real contact, context, stated next step, recency and opt-out. Recommend no follow-up when inappropriate. If suitable, propose concise personal next message for content approval; separate send authorization required. Label the record EXISTING and exclude from 20 NEW daily people; capture planned next action in private state.
