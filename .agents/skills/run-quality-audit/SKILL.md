# run-quality-audit

Independently examine final list against `evals/EVALUATION_PLAN.md`. Flag unverified current positions, ambiguous people, stale sources, unsupported statements, duplicate human identities, no prior-state check, guessed email, low score, false quota completion, and unconsented messaging. Confirm actual native skill activation evidence; no evidence -> NOT VERIFIED. Produce PASS/FAIL/NOT_TESTED per major gate and block reporting candidate as CONTACT_READY when any mandatory field fails. Audit has NO power to authorize sending.
