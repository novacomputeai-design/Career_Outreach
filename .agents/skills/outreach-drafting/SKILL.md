# outreach-drafting

Draft only after verification, scoring and memory checks. One real specific reason to connect (with source), one truthful piece of candidate experience, one respectful request for a brief conversation. No generic compliments, pressure, invented common contacts, speculative vacancies or Nova Compute sales pitches. Distinguish draft content approval from subsequent separate send authorization. Return draft, cited facts, intended route, status PENDING_CONTENT_APPROVAL; NEVER transmit. A bulk list of drafted messages is not permission to send.
