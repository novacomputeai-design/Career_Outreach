# relationship-memory

Read `../../../references/private-memory-contract.md`. On Windows, the authorized minimal lookup gateway is `scripts/relationship-check.ps1 -PersonName <quoted exact name> [-ProfileUrl <individual URL>]`, invoked with `pwsh -NoProfile -File`; it briefly unlocks the user's DPAPI files in a separate process and runs a **read-only** SQLite check. Do not read or print DPAPI contents or environment variables yourself. Do not open raw SQLite or query the store directly from Codex. A lookup `NOT_FOUND_IN_LOCAL_STORE` means **UNVERIFIED**, not NEW. `FIRST_LEARNED` means user-reported first discovery, **not** prior outreach nor contact-readiness; `PREVIOUSLY_MET` is an existing relationship. This gateway neither inserts candidates nor sends messages. Lookup stable individual identity across aliases/changes of company; compare current discovery with prior runs, approvals, messages, replies, meetings and opt-outs. A past contact moves to FOLLOW_UP, not NEW. A previously recommended NEW person should not be counted again unless user explicitly resets eligibility. Opt-outs block all outreach. If authorized private state is unavailable, mark novelty UNVERIFIED and report zero confirmed NEW rather than claiming uniqueness. Store sensitive personal interactions only in a secure private system, not this repository.
