# relationship-memory

Read `../../../references/private-memory-contract.md`. Lookup stable individual identity across aliases/changes of company; compare current discovery with prior runs, approvals, messages, replies, meetings and opt-outs. A past contact moves to FOLLOW_UP, not NEW. A previously recommended NEW person should not be counted again unless user explicitly resets eligibility. Opt-outs block all outreach. If authorized private state is unavailable, mark novelty UNVERIFIED and report zero confirmed NEW rather than claiming uniqueness. Store sensitive personal interactions only in a secure private system, not this repository.
